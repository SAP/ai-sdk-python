# SAP Cloud SDK for AI (Python) - Evaluations

Evaluations client for the SAP generative AI SDK. Provides tooling to configure
and run evaluation flows against orchestration deployments, collect metrics, and
work with datasets (via `pandas`).

The optional `[amazon]` extra adds AWS S3 support (`boto3`/`botocore`) for
reading and writing evaluation artifacts from object stores.

## Installation

    pip install sap-ai-sdk-evaluations            # core evaluations
    pip install "sap-ai-sdk-evaluations[amazon]"  # + AWS S3 artifact storage
