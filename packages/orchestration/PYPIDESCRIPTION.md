# SAP Cloud SDK for AI (Python) - Orchestration

Orchestration service client for the SAP generative AI SDK. Provides
`OrchestrationService` and the full orchestration configuration model set
(templating, content filtering, data masking, document grounding, translation,
embeddings, tools, streaming) for the orchestration service of SAP AI Core.

## Installation

    pip install sap-ai-sdk-orchestration

## Usage

```python
from sap_ai_sdk_orchestration import OrchestrationService, OrchestrationConfig

service = OrchestrationService(config=OrchestrationConfig(...))
```
