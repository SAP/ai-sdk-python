# Release Notes
## openai-v1.0.0

### Features
- Initial release of `sap-ai-sdk-openai`, split out from `sap-ai-sdk-proxy`. Contains the native OpenAI client wrappers (`OpenAI`, `AsyncOpenAI`) and the module-level `chat`, `embeddings`, `responses`, and `completions` convenience attributes that route OpenAI API calls through the generative AI Hub of SAP AI Core.
