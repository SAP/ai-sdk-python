# SAP Cloud SDK for AI (Python): Core SDK
The Core SDK can be used to interact with SAP AI Core's lifecycle and administration APIs.
It extends the functionality of the sap-ai-sdk-base library.

The SDK formerly known as *AI Core SDK* was rebranded.

Use the new package name to install the SDK:
```
pip install sap-ai-sdk-core
```
The class names have not changed i.e., you can continue to use existing code.

**Note**: Content packages for AICore are no longer supported.

Renovate is set up for this repository. For further information, you can refer to their [official website](https://www.mend.io/mend-renovate/).

## Releasing to public PyPI

Please follow [this guide](https://github.com/SAP/ai-sdk-python/blob/main/docs/RELEASING.md) to release sap-ai-sdk-core to public PyPI repositories.
