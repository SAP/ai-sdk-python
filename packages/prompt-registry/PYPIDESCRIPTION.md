# SAP Cloud SDK for AI (Python) - Prompt Registry

Prompt registry client for the SAP generative AI SDK. Provides
`PromptTemplateClient` and `OrchestrationConfigClient` for managing prompt
templates and orchestration configurations in the prompt registry of SAP AI
Core.

## Installation

    pip install sap-ai-sdk-prompt-registry

## Usage

```python
from sap_ai_sdk_prompt_registry import PromptTemplateClient

client = PromptTemplateClient()
```
