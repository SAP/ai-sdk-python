# ColumnType

Supported column data types for the data schema.  Includes base types (string, numeric, date) and additional types derived from SAP CDS (https://cap.cloud.sap/docs/cds/types#core-built-in-types). Additional types are mapped to the corresponding base type internally. All values are lowercase for case-insensitive matching.
