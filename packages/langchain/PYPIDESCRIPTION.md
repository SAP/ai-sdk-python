# SAP Cloud SDK for AI (Python) - LangChain

LangChain integration for the SAP Cloud SDK for AI (Python). With this package you can
use LangChain with the generative models available in the generative AI Hub of SAP AI
Core, through drop-in replacements for the common LangChain model classes.

## Installation

The provider-specific LangChain libraries are optional extras. Install only the
providers you need:

    pip install "sap-ai-sdk-langchain[openai]"
    pip install "sap-ai-sdk-langchain[amazon]"
    pip install "sap-ai-sdk-langchain[google]"

To install support for all providers:

    pip install "sap-ai-sdk-langchain[all]"

## Configuration, Usage

Please refer to the official documentation hosted on [help.sap.com](https://help.sap.com/doc/generative-ai-hub-sdk/CLOUD/en-US/index.html) for details on how to configure and use the SAP Cloud SDK for AI (Python).
