# Release Notes
## rpt-v1.0.0

### Features
- Initial release of `sap-ai-sdk-rpt`, split out from `sap-ai-sdk-proxy`. Contains the native SAP RPT client (`RPTClient`) and its pydantic request/response models (`RPTRequest`, `RPTResponse`, `PredictionConfig`, `TargetColumn`, `DataType`, …) for tabular predictions through the generative AI Hub of SAP AI Core.
