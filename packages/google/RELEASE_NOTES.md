# Release Notes
## google-v1.0.0

### Features
- Initial release of `sap-ai-sdk-google`, split out from `sap-ai-sdk-gen`. Contains the native Google GenAI client (`Client`, `AICoreDynamicTransport`, `AsyncAICoreDynamicTransport`). The langchain adapters (`ChatGoogleGenerativeAI`, `GoogleGenerativeAIEmbeddings`) are available via the optional `[langchain]` extra.
